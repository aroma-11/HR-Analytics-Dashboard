# HR Analytics Dashboard | Power BI

## Project Overview

The HR Analytics Dashboard is a business intelligence project developed using Microsoft Power BI to analyze employee data and generate insights into workforce distribution, employee attrition, and key HR performance metrics. It facilitates data-driven decision-making through interactive visualizations and analytical reporting.

## Project Objectives

- Analyze employee data and workforce distribution.
- Examine employee attrition patterns and trends.
- Monitor key HR performance indicators.
- Identify workforce trends across departments and job roles.
- Present analytical findings through interactive visualizations.
- Support informed, data-driven HR decisions.

## Tools and Technologies

- **Microsoft Power BI:** Dashboard development and data visualization.
- **DAX (Data Analysis Expressions):** Calculation of measures and key performance indicators, where applicable.
- **Power Query:** Data cleaning and transformation, where applicable.

## Dashboard Features

- **Employee Overview:** Analysis of workforce distribution and employee metrics.
- **Attrition Analysis:** Examination of employee turnover patterns.
- **Department Analysis:** Comparison of workforce metrics across departments.
- **Job Role Analysis:** Evaluation of employee distribution across job roles.
- **HR Performance Metrics:** Visualization of relevant workforce indicators.
- **Interactive Filtering:** Exploration of data across available categories.

## Business Questions

The dashboard is designed to address key HR-related business questions:

1. What is the total number of employees?
2. What is the employee attrition rate?
3. Which departments experience higher employee attrition?
4. How are employees distributed across different job roles?
5. What workforce trends can be identified through data analysis?

## Business Value

The dashboard transforms employee data into meaningful insights, enabling organizations to monitor HR metrics, identify workforce trends, improve reporting efficiency, and support employee retention strategies. It demonstrates the application of business intelligence in HR analysis and organizational decision-making.
